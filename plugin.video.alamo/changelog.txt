v1.0.0
- First release
- Sports, TV and Movies only
- Custom poster-first UI: home hero + rows, poster grid, detail page, source scanner
- TMDB metadata with sqlite caching
- Pluggable provider system with parallel scanning and ResolveURL support
- Built-in M3U / JSON playlist provider for Sports

v1.0.1
- Fix: add-on settings dialog showed no options (invalid <level>4</level> in the
  new settings schema); rewritten in Kodi's classic settings format with plain
  English labels so it cannot depend on string localisation
- New: "Enter / test TMDB API key..." button that validates the key against TMDB
- New: first run and empty Movies/TV now offer the keyboard prompt directly

v1.0.2
- Movies, TV and Sports grids: every tile now has a title caption, and the
  focused tile also shows the title over the artwork
- Home: the focused row is pinned in place - the row block slides up one pitch
  per row instead of the viewport scrolling, so no row can fall off screen
- Home: unfocused rows fade back to 38%, and rows scrolling past the top now
  disappear behind the hero instead of drawing over it
- Home: row navigation uses fallback lists so empty rows are skipped
- Category tiles use portrait posters so they are not stretched in a 2:3 frame

v1.0.3
- Sections now open nested instead of closing first, so Kodi's own menu is never
  visible between two Alamo screens
- Full-screen branded loading screen with logo, spinner and "Loading Movies"
- Category tiles build their artwork on a worker thread, 8 requests in parallel,
  so a section opens instantly and fills in
- Search removed from the rail: every section has its own Search tile and a
  Search button in the header (Movies / TV / Sports search their own content)
- Thumbnails have rounded corners matching the focus ring
- The focus ring, title overlay and highlight now appear only on the row that
  actually has focus - previously every row showed its selected tile as focused

v1.0.4
- Scraper engine: HosterScraper base class handling search, page fetch, link
  harvesting, matching, dedupe, host validation and caching
- Config-driven scrapers: add a site with a JSON file, no Python required
- Release parsing: quality, source, codec, audio, HDR, size, SxxEyy
- Title matching by containment with year and extra-word gates, so
  "Batman Begins" is never returned for "The Batman"
- Internet Archive provider: public domain film, direct MP4s, quality read from
  real pixel dimensions, extras and same-titled home movies filtered out
- HTTP layer with retries, pooled per-thread sessions and bot-wall detection
- New settings: Internet Archive toggle, hide unresolvable links, source cap
- docs/SCRAPERS.md and a site config template

v1.0.5
- Fix: the add-on declared script.module.resolveurl 5.1.0 as an optional
  dependency. In Kodi, optional means "need not be installed" - but if it IS
  installed it must satisfy the version, and an older ResolveURL made Kodi
  silently refuse to install or update The Alamo while still updating the
  repository. ResolveURL is imported lazily in code, so the declaration is gone
- Fix: script.module.requests requirement lowered from 2.27.1 to 2.22.0
- The installed version is now shown at the bottom of the sidebar
- New tests assert dependencies stay minimal and ResolveURL is never declared
